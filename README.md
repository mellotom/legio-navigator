# legio-navigator

travelers guide for navigating the legio starsystem: a one-page reference for the **noise engineering legio** platform. all 23 noise engineering firmwares (oscillators and voices, drums, effects) and the community firmwares, with every encoder, knob, switch and jack mapped from the official panel overlays, links to each manual or repository, how to swap firmware, and a star map.

sources: the noise engineering legio printable overlays and manuals, altstrument.org, and each community developer's repository.

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with noise engineering or any firmware developer.
